## 확인하지 못한 것

**원본 저장소 전체를 체크아웃하거나 기존 rp_studio를 실행하지 않았습니다.**
보완 테스트는 원본의 공개 코드에서 확인한 데이터 구조를 바탕으로 한 합성 입력/출력 계약을
사용했습니다. 새 테스트가 통과했다고 실제 한글 렌더링·PPTX 외관이나 원본 전체 회귀시험이
통과했다고 주장하지 않습니다.

3건의 통합 테스트는 원본 `rp_core`, `rp_render`, `rp_studio`가 없어서 명시적으로 skip했습니다.
실제 저장소에 적용한 뒤 기존 실행 환경에서 아래 명령으로 원래 테스트와 통합 테스트를
함께 실행해야 합니다. 의존성 또는 한글 폰트가 없으면 임의로 테스트 성공 처리하지 않습니다.
