# 서귀포시 직원용 AI 카드뉴스

## 목적과 독자

서귀포시 직원이 AI 관련 개념을 이해하고 업무에서 적용할 방법을 익히도록 제작함. 개발 지식을 전제하지 않음. 한 편에서 개념 하나와 활용 예시 하나를 설명함. 주민용 홍보나 기관의 공식 지침으로 표시하지 않음.

## 내용 구성

어려운 개념은 [업무 예시와 설명 그림](visual-explanations.md)을 적용함. 직원에게 익숙한 업무 상황을 먼저 제시한 뒤 그 안에서 개념을 설명함. 같은 예시를 여러 장에 이어 사용하고 카드 아래 여백을 관계·포함·변경 전후 등을 보여주는 그림에 활용함. 아래 구성표는 선택 기준이며 용어 설명부터 시작하는 고정 순서가 아님.

기본은 8장, 주제가 단순하면 5~7장으로 조정함. 사용자 요청 장수가 우선이며 최대 12장임. 정의와 구성요소 설명이 겹치면 합치고 예시를 보강함. 시의성 있는 소식이 없으면 유행·최신성 문구를 만들지 않음.

| 순서 | 역할 | 내용과 표현 |
|---|---|---|
| 1 | 표지 | 직원이 궁금해할 주제를 제목으로 제시하고 학습 범위를 설명함 |
| 2 | 개념 | 쉬운 정의 한 문장, 낯선 용어의 뜻 설명 |
| 3 | 비교 | 혼동하기 쉬운 두 개념을 같은 기준으로 비교함 |
| 4 | 업무 활용 | 공개자료 정리·문안 초안·회의 준비 등 구체적 상황 하나 제시 |
| 5 | 실행 예시 | 바로 따라 할 수 있는 짧은 요청문이나 3~6단계 절차 |
| 6 | 확인 방법 | 결과를 원문과 대조하는 방법이나 적용 조건 설명 |
| 7 | 주의사항 | 해당 주제와 관련 있는 한계·정보 입력 범위·확인 책임 설명 |
| 8 | 요약 | 핵심 3개와 다음 행동 하나, 필요할 때 다음 주제 안내 |

제목은 1~2줄, 본문은 2~4항목을 우선함. 단계형은 최대 6항목 권장. 본문은 한 항목당 1~2문장, 긴 내용은 다음 장으로 분리함. 제목만 읽어도 내용의 순서를 이해할 수 있어야 함. 영문 약어는 처음에 쉬운 뜻을 붙이고 이후에는 같은 표현을 사용함. 제목·본문·그림 설명·캐릭터의 말은 친근한 해요체로 작성함. 친근한 표정과 짧은 안내를 사용하되 유아용 말투, 능력 과장, 성과 수치 창작을 피함.

가상 예시는 각주에 가상 예시라고 표시함. 출처가 있는 사실, 기관 지침, 제작자의 활용 제안을 구분함. 승인 도구·입력 가능 자료·보존 기간 등 기관별 조건을 추정하지 않음. 출처 [번호]는 각주에, 문서명·URL·기준일·해당 위치는 SOURCES.md에 기록함. 도구 기능·요금·정책처럼 바뀌는 정보는 제작 시점의 공식 자료로 확인함.

## 디자인과 캐릭터

별도 지시가 없는 새 카드의 좌측 상단은 `오늘의 주제: OOO` 형식으로 작성함. `plan.json`의 `series_title`에 `오늘의 주제: 임베딩`처럼 짧은 주제명을 넣음. 미리보기도 같은 값을 사용하며 예제를 복사할 때 이전 주제명이 남지 않도록 바꿈. 사용자 지정 문구가 있으면 그대로 사용하며 렌더러에서 접두사를 강제로 붙이지 않음.

| 항목 | 기준 |
|---|---|
| 규격 | 4:5, 기본 2160×2700, 일반 출력 1080×1350 |
| 배경과 본문 | 밝은 바탕, 흰 본문 영역, 짙은 글자색 |
| 테두리 | 제주그린 #00A074, 제주블루 #0173BC, 제주오렌지 #F18101 |
| 색상 적용 | 장별 테두리를 세 색으로 순환함. 하단 3색 띠는 사용하지 않음. 테두리 상자 바깥 왼쪽 위에 오렌지·블루·그린 순서로 같은 크기의 원 3개 배치. 원 전체가 상자 위에 위치해야 함. 주의사항은 오렌지 테두리와 한글 분류 표시 사용 |
| 글꼴 | Pretendard Regular/Bold 정적 폰트. 본문 최소 30px, 1080px 너비 기준 |
| 공통 요소 | 시리즈명, 쪽수, 한글 분류 표시, 큰 제목, 본문, 설명 그림, 출처. 핵심 정리 상자는 필요한 장에 사용 |
| 캐릭터 | 표지와 마지막 장에는 귤귤·하르방·한라 모두 배치, 중간 장에는 설명 역할에 따라 선택. 애니메이션 시트에서 추출한 동작 포즈 사용 |
| 배치 | 글자와 비교·요약 상자의 실제 영역을 측정하고 남은 여백에서 캐릭터 위치를 선택함. 특정 모서리에 고정하지 않음 |
| 분류 라벨 | 사각형 안에서 텍스트 가로·세로 가운데 정렬. PNG와 편집형 PPTX에 같은 정렬 적용 |
| 문안 배치 | 제목·본문·요약을 읽는 순서대로 배치. 요약 상자는 본문 다음에 두고 본문과 멀리 떨어뜨리지 않음 |

원본 PNG는 assets/jeju-pets에 포함됨. 새 캐릭터를 그리거나 모양·색·이름을 바꾸지 않음. 원본 저장소의 캐릭터는 학습 안내에 활용하며 공식 기관 마스코트라고 표시하지 않음. 기관명·로고는 기존 승인 규칙을 따름. 실제 발행 주체가 정해지지 않으면 임의 기관 로고를 넣지 않음.

캐릭터의 역할·크기·장면 선택은 [캐릭터 활용 기준](character-scenes.md)을 적용함. 남은 모서리를 찾기 전에 캐릭터가 질문하거나 설명할 대상을 정함.

### 동작 포즈 선택

캐릭터별 7종, 총 21종의 투명 배경 PNG를 포함함. 192×208 원본 프레임을 그대로 추출하며, 정면 대기 포즈를 모든 장에 반복하지 않음. PNG는 동작 중 한 장면을 표시하는 정지 이미지임. 원본의 픽셀·비율·투명도를 유지하고 캐릭터 전체가 보이도록 배치함.

| 카드 용도 | 포즈 파일명 접미사 | 동작 |
|---|---|---|
| 표지 | wave / explain / wave | 두 캐릭터의 손 인사와 하르방의 설명 동작 |
| 개념 | think | 생각하는 표정과 손 동작 |
| 비교·업무 활용 | explain | 팔을 펼치거나 내밀며 설명 |
| 따라 하기 | walk-left / walk-right | 배치 위치에 따라 본문 쪽으로 걷는 동작 |
| 주의사항 | caution | 집중하는 표정 |
| 요약·마지막 장 | cheer | 손을 모으고 기뻐하는 동작 |
| 별도 편집용 | walk-right | 오른쪽으로 걷는 동작 |

`{캐릭터 ID}-{포즈}.png` 형식으로 선택함. 자동 제작은 위 기준으로 결정하며 별도의 입력 필드는 없음. 포즈 목록은 `assets/jeju-pets/manifest.json`, 그림 목록은 저장소의 `docs/pet-poses.html`에 수록함. manifest에는 원본 시트의 해시와 0부터 시작하는 행·열, 추출 영역, PNG 해시를 기록함. `scripts/extract_pet_poses.py --source-root <원본 저장소> --out <새 폴더>`로 원본 일치 여부를 확인하고 다시 추출할 수 있음.

원 3개는 1080px 너비 기준 지름 20px, 왼쪽 좌표 48·82·116px, 위쪽 좌표 96px로 배치함. 테두리 상자는 x=48px, y=130px에서 시작하므로 원의 아랫부분과 테두리 윗선 사이에 14px 간격을 둠. 첫 원의 왼쪽을 테두리 왼쪽과 맞추고, 원 전체를 상자 바깥에 둠. 2160px 출력은 두 배 크기로 적용함. 편집형 PPTX에서도 타원 도형 개체로 유지함.

분류 라벨은 176×48px이며 글자의 실제 경계를 기준으로 가로·세로 중앙에 정렬함. 제목은 기본 54px, 표지는 70px, 본문은 34px에서 시작함. 제목 줄 간격은 글자 크기의 1.22배, 본문은 1.4배로 적용하고 띄어쓰기 단위를 우선하여 줄바꿈함. 단어 하나가 줄보다 긴 경우에는 글자 단위 줄바꿈을 허용함. 본문 최소 크기 30px를 유지하며 내용을 임의로 생략하지 않음.

비교형은 제목과 설명을 분리하여 제목만 굵게 표시함. 순서 번호는 밝은 바탕 안에 가운데 정렬하고, 요약은 필요한 장에서 옅은 바탕으로 구분하며 왼쪽 색상 선을 반복하지 않음. 반복되는 학습 안내 문구를 장마다 넣지 않음.

중간 장의 캐릭터는 제목 옆, 본문 옆, 요약 아래의 빈 공간을 검사하여 배치함. 글자·비교 상자·요약 상자와 24px 이상 간격을 확보하고, 본문 길이에 따라 위치와 크기를 조정함. 표지와 마지막 장은 3종을 모두 배치하며, 각자 안내할 대상이 있으면 위치를 나눌 수 있음. 여백이 부족하면 문안을 줄이거나 장을 나누도록 안내하며 글자를 가리거나 캐릭터를 생략하지 않음.

분석 참고: https://www.instagram.com/p/De3w1C4ny6J/ (2026-10-27 확인). 참고한 요소는 일정한 정보 배치, 정의·비교·절차·주의사항·요약의 구성, 표지와 마지막 장의 캐릭터 배치임. 원문 문구·계정 표시·캐릭터·고유 그래픽은 복제하지 않음. 제주 색상은 기존 저장소의 사용자 팔레트를 사용하며 공식 인증 색상이라는 주장을 하지 않음.

## 제작 입력

`build --profile seogwipo-ai`로 제작함. 기존 jeju·neutral 프로필은 일반 카드뉴스용으로 유지함. 입력은 기존 plan.json에 장별 layout과 takeaway를 선택적으로 추가함.

| 필드 | 의미 |
|---|---|
| layout: definition | 개념 설명 목록 |
| layout: list | 업무 활용 목록 |
| layout: compare | bullets 2개를 좌우 비교 상자로 표시. 각 본문의 첫 줄에 비교 대상 명시 |
| layout: steps | 번호가 있는 실행 순서 |
| layout: caution | 오렌지 테두리와 주의사항 표시 |
| layout: summary | 번호가 있는 핵심 요약 |
| takeaway | 별도 상자에 표시할 핵심 문장. 최대 140자이나 1~2줄 권장 |

layout을 생략하면 마지막 장은 summary, 나머지는 list임. 표지 분류는 AI 기초로 표시함. role은 cover/body/closing 순서를 유지함. layout/takeaway는 새 프로필에서만 지원하며 다른 프로필과 이전 render 명령에서는 명시적으로 오류를 반환함. 지원하지 않는 문안을 조용히 버리지 않음.

제작 예시: assets/seogwipo-ai-example/plan.json. 이 파일은 가상 업무를 사용한 디자인 시험 자료이며 승인된 교육 원고가 아님. 실제 게시용은 사용자가 지정한 주제로 출처를 확인하고 새 기획안을 작성함.

## 검수

- 8장 구성의 역할이 겹치지 않고 업무 예시가 이해 가능한지 확인함.
- 세 캐릭터의 동작 포즈와 세 테두리 색, 주의사항 표시, 비교와 단계형 배치를 확인함.
- 원 3개 전체가 테두리 바깥 왼쪽 위에 있고, 오렌지·블루·그린 순서인지 확인함. 하단 3색 띠가 없는지도 확인함.
- 분류 라벨 글자의 가로·세로 가운데 정렬과 본문 길이에 따른 캐릭터 위치 조정을 확인함.
- 본문·핵심 정리·출처가 잘리거나 캐릭터에 가려지지 않는지 PNG 전 장 확인함.
- 1080px와 2160px 출력의 글자 대비·경계 보고서를 확인함.
- 편집형 PPTX에 문안과 세 캐릭터 이미지 개체가 포함되는지 확인함. PowerPoint에서 연 결과는 별도 검수함.
- 원본 캐릭터 출처와 해시를 결과 ZIP에 포함함. 사실 확인과 시각 검수의 수행 범위를 별도로 보고함.

Pretendard 공식 배포본: https://github.com/orioncactus/pretendard/releases . 폰트는 결과 ZIP과 PPTX에 포함하지 않음. 편집형 PPTX를 여는 PC에도 Pretendard 설치 필요.
