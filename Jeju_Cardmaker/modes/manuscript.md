# 원문에서 카드뉴스 만들기

원고·문서·보도자료·기존 plan.json을 받은 경우에 적용함. 카드뉴스로 줄여도 대상·숫자·단위·기간·조건·제외 사항의 뜻을 보존함.

```text
python <SKILL>/scripts/Jeju_Cardmaker.py extract --input <INPUT> --out <PROJECT>/source.json
```

기존 추출기의 지원 형식과 경고를 확인함. 이미지·표·스캔 영역은 직접 확인하며 OCR이나 구형 HWP 지원을 추정하지 않음. 원문 문장을 보존하는 요청이면 인용과 설명을 구분하고 인용의 종결을 강제 변환하지 않음.

요약한 문장과 원문 위치를 SOURCES.md에 연결함. 새 예시를 추가하면 가상 사례로 표시함. 그림 속 수치·대상도 원문과 대조함.

완료 기준: 원문 사실과 새 설명의 경계가 분명하고 생략 때문에 의미가 바뀌지 않음. 한 장에 들어가지 않으면 글자를 무한히 줄이지 말고 장 구성을 조정함.
