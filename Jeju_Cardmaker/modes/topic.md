# 주제에서 카드뉴스 만들기

개념·아이디어만 받은 경우에 적용함. 주제와 독자가 정해져 있으면 불필요한 확인 질문 없이 시작함.

1. 개념과 한계를 공식 자료·원 논문에서 확인하고 SOURCES.md에 위치와 확인일을 기록함.
2. 직원이 아는 업무 하나를 선택함. 행사 준비·회의자료 찾기·안내 문안 정리 중 개념과 맞는 예시를 고름. 모든 주제를 같은 행사로 바꾸지 않음.
3. 각 장에서 알게 될 내용을 한 문장으로 정함. 질문·쉬운 정의·그림·확인할 점·작은 연습을 주제에 맞게 배치함.
4. plan.json에 문안, diagrams.json에 그림의 대상·단계·관계를 작성함. 사실·가상 예시·제작자 제안을 구분함.
5. 캐릭터의 역할과 포즈를 정하고 해요체로 작성함. 낯선 약어는 처음에 풀어 설명함.

완료 기준: 제목·본문·그림이 같은 업무 예시를 일관되게 사용하고 모든 사실 주장에 근거가 있음. 장수나 책 분량을 채우기 위한 반복·부록은 추가하지 않음.
