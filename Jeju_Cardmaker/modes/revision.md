# 기존 카드뉴스 수정

사용자가 지정한 미리보기와 실제 제작 폴더의 plan.json·diagrams.json·렌더러를 확인함. 여러 판본이 있으면 대화와 파일 기록으로 수정할 원고를 식별함. 이전 결과는 보관하고 새 폴더로 제작함.

- 문안 수정은 제목·본문·말풍선·그림 라벨·출처 안내까지 범위를 확인함.
- 배치 수정은 색·글꼴·테두리 밖 원·중앙 라벨·캐릭터 원본 등 기존 기준을 보존함.
- 주제를 바꾸면 이전 주제의 그림·설명·출처를 그대로 남기지 않음.
- PNG나 PPTX만 고쳐 원본 JSON과 달라지게 두지 않음. 같은 제작 자료에서 다시 생성함.

수정한 장의 상세 검수와 전체 장의 연속성 검수를 수행함. 이전 review.json은 새 초안에 재사용하지 않음. 디자인 확인과 새 문안 승인을 구분함.
