## 미검증 또는 차단된 범위

### 사용자 Windows PC 및 Codex 호스트

DESKTOP의 `agent_guide`, `runtime_diagnostics` 두 호출 모두 다음 오류를 반환했다.

```text
FORBIDDEN: This conversation does not support developer MCPs
```

사용자 PC의 Python/폴더/Codex 버전은 읽지 못했으며 파일 쓰기나 설치를 수행하지 않았다. Codex의 실제 스킬 선택 화면에서 인식/호출하는 종단 테스트도 미실행이다. 현재 배포본은 공식 스킬 형식에 맞춰 작성하고 파일/지침 구조를 검사했다.

### Windows PowerShell 설치

`install.py`는 임시 경로에서 실제 실행 검증했다. `install.ps1`은 소스 정적 검토만 했으며 Windows PowerShell 또는 pwsh 실행 검증은 하지 않았다. Windows의 실행 정책·Python 런처·인코딩 환경 차이는 실제 PC에서 확인이 필요하다. 설치 스크립트는 실행 정책을 변경하지 않는다.

### 원본 다운로드, 패키지 설치 및 API

컨테이너의 Git clone은 호스트 이름 해석 실패로 완료하지 못했다. 원본 공개 코드의 본문과 함수 시그니처는 웹 조회로 확인했다. 원본 전체 저장소/이미지 템플릿/MI 로고의 실행 환경을 만들지 않았으며 API 기획·GPT Image·원본 문안 PPTX 내보내기는 실제 원본과 끝까지 실행하지 않았다.

`bootstrap.py`의 네트워크 opt-in 차단은 테스트했지만, 실제 PyPI 다운로드를 포함한 깨끗한 Windows 가상환경 설치는 미실행이다. 패키지 버전 범위 안에서도 이후 배포된 의존성의 호환성은 달라질 수 있다.

## 재현 명령

패키지 루트에서 기본 의존성이 있는 Python을 사용한다.

```text
python -m unittest discover -s releasepick/tests -v
python releasepick/scripts/releasepick.py doctor
```

본 보고는 시행한 테스트의 결과만 기록한다. 실제 정책 내용의 정확성, 기관 규정 적합성 또는 법적 효력을 인증하지 않는다.
